# Demo folders

Each subfolder inside this directory represents one Flash project or archived demo.

## Suggested layout

```text
demos/
  flash-nebula/
    index.html
    nebula.swf
  demo-02/
    index.html
    demo.swf
```

Keep the SWF file in the same folder as its HTML page. This makes each demo easier to move, back up, and keep self-contained.
